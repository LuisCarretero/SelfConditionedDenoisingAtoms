## SCD paper LaTeX sources

This directory holds the SCD paper LaTeX sources (referenced from `main.tex`, which `\input`s the topic-specific `.tex` files). Extracted baseline numbers for the three MLIP_propbench tasks — QM9 HOMO, Matbench `mp_gap`, and LBA (id30/id60) — live in [baselines.md](baselines.md), annotated by training regime (scratch vs pretrained+SFT) and source `.tex` file.
